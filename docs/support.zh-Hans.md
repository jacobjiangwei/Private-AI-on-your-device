# PrivateAI 帮助中心

## 系统要求

PrivateAI 当前需要 macOS 14 或更高版本、适用于 macOS 的 Ollama，以及至少一个已安装的 Ollama 模型。下载模型需要额外磁盘空间，性能取决于 Mac、模型、上下文长度和量化方式。

## 首次启动

1. 从 Ollama 官方 macOS 下载页面安装并打开 Ollama。
2. 安装任意兼容的 Ollama 模型。PrivateAI 会显示可复制的推荐 Qwen 命令。
3. 返回 PrivateAI 并选择“重新检查”。
4. 从模型状态控件中选择已安装模型。

PrivateAI 不会替用户安装软件，也不会在未经用户操作时执行模型下载命令。

## 文档

通过回形针按钮、拖放或从 Finder 粘贴文件对象来添加文件。在对话中输入文件系统路径不代表读取授权。导入的文档会进入本地文档资料库，并可在后续对话中复用。

本版本支持文本型 PDF、常见文本与办公文档、源代码文件和静态图像。不支持没有可提取文本的扫描 PDF。

## 删除本地数据

- 从侧边栏删除对话。
- 从“记忆”中删除记忆。
- 从文档资料库删除文档，以移除沙盒副本、提取文本和缓存的本地模型摘要。
- 移除 PrivateAI 应用容器，以删除 PrivateAI 保留的全部数据。

删除对话不会删除文档资料库中的文档。

## 网络活动

核心模型推理仅发送给同一台 Mac 上的 Ollama。当请求需要最新信息时，PrivateAI 可能使用 DuckDuckGo 搜索、读取请求的网站、检查公共网络上下文，或使用 Apple 地图执行已获授权的附近搜索。工具活动和来源会显示在对话中。

## 故障排除

- 如果 PrivateAI 无法连接，请确认 Ollama 应用已打开，然后选择“重新检查”。
- 如果没有显示模型，请在 Ollama 中安装模型后选择“重新检查”。
- 如果无法打开本地数据，请使用“重试”。PrivateAI 不会重置数据或切换到云端模型。
- 可以从工具栏打开日志，日志会保留在这台 Mac 上。

## 联系方式

请创建 GitHub issue，并附上 PrivateAI 版本、macOS 版本、Ollama 版本、所选模型和准确的错误消息。请勿在公开 issue 中提交敏感文档、对话内容、API 密钥或其他凭据。安全漏洞请按照 `SECURITY.md` 通过私密渠道报告。
