# PrivateAI 隐私政策

生效日期：2026-08-29

PrivateAI 目前是一个正在从头重建的 macOS 应用开发骨架，并非受支持的产品版本。本政策只描述当前仓库中已经提交的代码；规划中的行为应记录在产品和架构文档中，而不应作为当前数据流陈述。

## 核心 AI 处理

当前骨架尚未实现对话，不会连接 Ollama 或其他模型提供方，不会处理提示词，也不会向本地或云端模型发送 AI 内容。

## 保存在 Mac 上的数据

当前 Xcode 骨架只包含模板性质的本地持久化代码，尚不会保存对话、记忆、导入文档、提取文本、模型摘要或产品诊断日志。本地开发构建产生的数据会保留在该构建的应用容器中，直到通过开发工具或删除容器将其移除。

## 网络功能

当前骨架尚未实现网页搜索、URL 读取、公网 IP 查询、附近搜索、产品分析、广告或其他产品网络功能。

## 文件访问

当前骨架尚未实现文件选择、拖放、粘贴导入或文档处理。

## 安全与保留

当前开发构建使用 Xcode 项目中配置的 entitlement 和沙盒设置，尚无对话、记忆或文档层面的产品删除控件。移除开发构建的应用容器会删除该容器中保留的数据。

## 变更与联系

如有重大变更，本政策会更新生效日期。隐私问题请使用仓库的公开支持渠道；安全问题请使用 GitHub 的私密漏洞报告渠道。
