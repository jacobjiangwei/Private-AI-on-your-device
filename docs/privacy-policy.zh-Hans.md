# PrivateAI 隐私政策

生效日期：2026-08-28

PrivateAI 是一款通过 Ollama 使用本地 AI 模型的 macOS 应用。本政策说明应用处理哪些数据、数据会去往何处，以及用户如何删除数据。

## 核心 AI 处理

PrivateAI 仅将核心对话提示词、有限的文档上下文和规范化图像发送给同一台 Mac 上运行的 Ollama 服务。PrivateAI 不提供云端模型备用方案、不要求账户、不显示广告，也不包含产品分析追踪。

## 保存在 Mac 上的数据

PrivateAI 会在 macOS 沙盒容器中保存对话、本地记忆、诊断日志、导入的文件副本、提取文本和本地模型生成的文档摘要。这些数据不会发送给开发者，并会保留到用户主动删除或移除应用容器为止。

删除对话不会删除文档资料库中保留的文档。从文档资料库删除文档时，其沙盒副本、提取文本和缓存的本地模型摘要会被永久移除。用户也可在“记忆”视图中删除记忆。

## 网络功能

当用户请求需要当前或外部信息时，PrivateAI 可以使用以下网络功能：

- 网页搜索会将搜索查询发送给 DuckDuckGo。
- URL 读取会连接用户请求或为任务选择的网站。
- 公共网络上下文可能连接 Cloudflare 或 ipify，以确定当前公网 IP 地址。
- 仅当用户请求授权使用当前位置且 macOS 已授予权限时，附近搜索才会使用 Apple 定位和地图服务。
- 设置指引可以在用户的浏览器中打开 Ollama 官方网站。

PrivateAI 会在对话中显示工具活动和来源。外部服务会根据其各自的隐私政策处理请求。PrivateAI 不会出售用户数据，也不会将这些请求用于广告或追踪。

## 文件访问

PrivateAI 仅在用户通过 macOS 授权的选择、拖放或粘贴操作提供文件后读取该文件。在对话中输入文件系统路径不代表授权。导入的文件会复制到应用沙盒中，随后释放外部安全作用域。

## 安全与保留

PrivateAI 使用 macOS App Sandbox，并仅请求用户所选文件的只读权限。用户可以通过对话、记忆和文档资料库中的删除操作控制保留。移除应用容器会删除 PrivateAI 在本地保留的所有数据。

## 变更与联系

如有重大变更，本政策会更新生效日期。隐私问题请使用仓库的公开支持渠道；安全问题请使用 GitHub 的私密漏洞报告渠道。
